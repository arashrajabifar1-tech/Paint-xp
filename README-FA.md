# XP Paint — نقاشی کلاسیک به سبک ویندوز XP

برنامه نقاشی با ظاهر کلاسیک Windows XP Paint، آیکن لیوان مدادها و قلم‌موهای رنگی، و نام XP Paint.

## امکانات
- ابزارهای قلم، قلم‌مو، اسپری، پاک‌کن، سطل رنگ، انتخاب رنگ، متن و شکل‌ها
- پالت رنگ، بزرگ‌نمایی، شبکه، تصویر بندانگشتی و تغییر اندازه بوم
- چرخش، برگردان، کشش، کج‌کردن و وارونگی رنگ
- بازکردن و ذخیره تصویر در قالب‌های پشتیبانی‌شده مرورگر
- ذخیره خودکار محلی و نسخه PWA آفلاین پس از اولین مراجعه
- ذخیره مستقیم تصویر در پوشه عمومی Pictures/XP Paint گوشی‌های اندرویدی جدید
- فرمان خروج بومی اندروید برای بستن درست برنامه
- گردش‌کار GitHub Actions برای ساخت APK آزمایشی

## ساخت APK
راهنمای [ANDROID-BUILD-FA.md](ANDROID-BUILD-FA.md) را دنبال کن. در GitHub به Actions برو، گردش کار **Build Android APK** را اجرا کن و Artifact با نام `xp-paint-android-debug` را دریافت کن.

**توجه:** پنل Layers فعلی فقط نمونه اولیه رابط کاربری است و ترکیب چند لایه مستقل هنوز کامل نشده است. نقاشی‌ها به سرور ارسال نمی‌شوند؛ مگر آن‌که کاربر خودش خروجی بگیرد یا اشتراک‌گذاری کند.
