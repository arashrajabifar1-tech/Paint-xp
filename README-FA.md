# تیزاندیش پینت XP

برنامه نقاشی با ظاهر کلاسیک Windows XP Paint، مناسب مرورگر، نصب PWA و بسته‌بندی اندروید.

## امکانات
- قلم، قلم‌مو، اسپری، پاک‌کن، سطل رنگ و انتخاب رنگ
- انتخاب مستطیلی و آزاد، متن و ابزارهای شکل
- پالت رنگ، بزرگ‌نمایی، شبکه، تصویر بندانگشتی و تغییر اندازه بوم
- چرخش، برگردان، کشش، کج‌کردن و وارونگی رنگ
- بازکردن و ذخیره تصویر در قالب‌های پشتیبانی‌شده مرورگر
- ذخیره خودکار محلی در مرورگر
- PWA قابل نصب و cache آفلاین پس از اولین مراجعه
- گردش‌کار GitHub Actions برای ساخت APK آزمایشی

## ساخت APK
راهنمای [ANDROID-BUILD-FA.md](ANDROID-BUILD-FA.md) را دنبال کن. در GitHub به Actions برو، گردش کار Build Android APK را اجرا کن و Artifact را دریافت کن.

**توجه:** پنل Layers فعلی فقط نمونه اولیه رابط کاربری است و ترکیب چند لایه مستقل هنوز کامل نشده است. فایل‌های نقاشی به سرور ارسال نمی‌شوند؛ مگر آن‌که کاربر خودش خروجی بگیرد یا اشتراک‌گذاری کند.
